# Farmbotic — Playtest QA

Independent QA testing project for the **Farmbotic** Steam Playtest.

The purpose of this repository is to document the testing process, gameplay observations, UX findings and reproducible issues identified during several playtest sessions.

## Testing Focus

* First-Time User Experience
* Gameplay and mission progression
* UX and UI observations
* Save and progression persistence
* Localization
* Loading and performance observations
* Reproducible bugs and improvement suggestions

## Test Environment

* **Game:** Farmbotic
* **Version:** 0.5.4
* **Platform:** Steam
* **OS:** Windows 11
* **Input:** Keyboard + Mouse
* **Hardware:** Intel Core i7-13620H / 16 GB RAM / Intel UHD Graphics

## Sessions

| Session    | Focus                        |
| ---------- | ---------------------------- |
| SESSION-01 | First-Time User Experience   |
| SESSION-02 | Progression and Save Testing |
| SESSION-03 | Final Verification           |


## Approach

Testing was performed through exploratory gameplay, documenting both positive and negative observations rather than treating every unexpected behavior as a bug.

Potential issues were investigated and, when possible, reproduced before being documented as bugs.
